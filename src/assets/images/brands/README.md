# Logos esperados (no incluidos)

Este proyecto no genera ni rediseña logos. Cuando estén disponibles los archivos optimizados para web, deben ubicarse en esta carpeta con estos nombres:

- `atora-studio-logo.png`: marca matriz y encabezado principal
- `atora-lms-logo.png`: producto ATORA LMS
- `atora-theme-logo.png`: producto ATORA Theme
- `atora-symbol.png`: símbolo aislado para favicon y usos compactos

Mientras no existan, el encabezado usa “ATORA Studio” como texto accesible.
