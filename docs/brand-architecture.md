# Arquitectura de marca — ATORA

Este repositorio construye el sitio oficial de **ATORA Studio** (marca matriz).

## Marcas y productos

1. **ATORA Studio**
   - Marca matriz y nombre del sitio.
   - Dominio futuro: `https://atora.studio`
   - Presentará el ecosistema completo y futuros productos.

2. **ATORA LMS**
   - Producto principal.
   - Plugin y plataforma de gestión educativa para WordPress.
   - No es la marca matriz.

3. **ATORA Theme**
   - Tema visual de WordPress diseñado para ATORA LMS.
   - Anteriormente se llamó “ATORA Studio”.
   - En este sitio debe comunicarse como **ATORA Theme**.
   - Importante: no modificar el código fuente del tema en este repositorio (solo el nombre comercial).

## Reglas de nomenclatura

- Usar **ATORA** en mayúsculas para nombres de productos y marca.
- No usar nunca “Atore”.
- Evitar afirmaciones comerciales no verificadas (precios, disponibilidad, promesas).
